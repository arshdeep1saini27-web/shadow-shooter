# SHADOW STRIKE

SHADOW STRIKE is a browser-based shooting game made using HTML, CSS, and JavaScript.

## Features

- Move your player around the arena.
- Aim with the mouse.
- Shoot enemy bots.
- Enemy bots chase and attack the player.
- Health, ammunition, and score counters.
- Reload your weapon.
- Collect health boosts.
- Win or lose screen with a play-again option.

## Controls

| Action | Control |
|---|---|
| Move | W, A, S, D or Arrow keys |
| Aim | Move the mouse |
| Shoot | Left mouse button or Space |
| Reload | R |

## How to Play

1. Open the game in Google Chrome or Microsoft Edge.
2. Click the START GAME button.
3. Move your player using WASD or arrow keys.
4. Aim using your mouse.
5. Shoot enemies and eliminate all bots.
6. Collect health boosts to restore health.
7. Try to achieve the highest score!

## How to Run Locally

1. Download the project files.
2. Open the project folder.
3. Double-click `index.html`.
4. The game will open in your browser.

No installation or build process is required.

## How to Publish Using GitHub Pages

1. Upload `index.html` and `README.md` to your GitHub repository.
2. Open repository Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select the `main` branch.
6. Select `/ (root)` folder.
7. Click Save.

Your game URL will look like:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/`
